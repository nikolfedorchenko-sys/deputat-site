# Сайт депутата Київради — лендінг + адмінпанель

Односторінковий адаптивний сайт українською для депутата Київради з повноцінною
адмінпанеллю за адресою **`/manager`**, через яку контент-редактор **без знання коду**
керує всім вмістом: новини, фотогалерея, тексти секцій, контакти, головне фото,
логотип і звернення з форми.

Стартовий контент уже заповнено реальними фактами (seed). Усе, що потребує уточнення,
позначено `[УТОЧНИТИ]` і редагується через адмінку.

---

## Стек

| Шар            | Технологія                        | Чому |
|----------------|-----------------------------------|------|
| Backend        | **Node.js + Express**             | один процес, без білд-кроку, легко хостити |
| Рендеринг      | **EJS (SSR)**                     | готовий SEO/OpenGraph без SPA |
| База даних     | **SQLite** (`better-sqlite3`)     | один файл `db/data.sqlite`, нічого не адмініструвати |
| Зображення     | **multer + sharp**                | валідація типу/розміру + автостиснення, файли в `/uploads` |
| Авторизація    | **express-session + bcryptjs**    | пароль хешується, сесія в cookie |
| Захист від спаму | **express-rate-limit + honeypot** | форма звернення |

---

## Вимоги

- **Node.js 18+** і npm.
- Для `sharp` і `better-sqlite3` на деяких хостингах може знадобитися компілятор
  (build-essential/python) — зазвичай ставиться автоматично з готових бінарників.

## Запуск локально

```bash
# 1. Перейти в папку проєкту
cd deputat-site

# 2. Встановити залежності
npm install

# 3. Створити .env з прикладу і задати свої значення
cp .env.example .env      # Windows: copy .env.example .env

# 4. Запустити
npm start
```

Відкрити:
- Сайт — <http://localhost:3000>
- Адмінка — <http://localhost:3000/manager>

> База даних і стартовий контент створюються автоматично при першому запуску.

## Змінні `.env`

| Змінна          | Опис |
|-----------------|------|
| `PORT`          | Порт сервера (за замовч. 3000) |
| `SESSION_SECRET`| Секрет для cookie. **Обов'язково** довгий випадковий рядок. |
| `ADMIN_USERNAME`| Логін для входу в `/manager` |
| `ADMIN_PASSWORD`| Пароль адміна (в базі не зберігається у відкритому вигляді — хешується `bcrypt` на старті) |
| `SECURE_COOKIES`| `1`, якщо сайт за HTTPS (cookie лише по захищеному з'єднанню) |

Згенерувати надійний `SESSION_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

## Що вміє адмінпанель `/manager`

- **Новини** — створення/редагування/видалення, статус *чернетка/опубліковано*,
  головне фото + галерея фото до поста, тег, дата.
- **Фотогалерея** — завантаження кількох файлів, підписи, drag&drop-перевпорядкування, видалення.
- **Тексти секцій** — гасло, біографія, освіта, кар'єра, блок діяльності, SEO-тексти.
- **Досягнення** — картки (додати/змінити/видалити + перевпорядкування).
- **Контакти** — адреса, телефони, email, графік, соцмережі, код карти Google Maps.
- **Головне фото / логотип / OG-зображення** — заміна одним кліком.
- **Звернення** — перегляд заявок з форми, позначка «опрацьовано», видалення.

Усі зображення проходять валідацію (тип, розмір ≤ 8 МБ) і автоматично стискаються
(`sharp`: макс. 1600px, прогресивний JPEG).

## Структура проєкту

```
deputat-site/
├─ server.js              # точка входу, сесії, безпека, маршрути, SSR головної
├─ db/database.js         # схема SQLite + seed
├─ middleware/
│  ├─ auth.js             # захист /manager і /api/admin
│  └─ upload.js           # multer(memory) + sharp
├─ routes/
│  ├─ public.js           # публічне читання + приймання звернень
│  ├─ admin.js            # захищений CRUD
│  └─ auth.js             # вхід/вихід
├─ views/
│  ├─ index.ejs           # публічна сторінка (7 секцій)
│  └─ manager/{login,dashboard}.ejs
├─ public/                # css, js, зображення-плейсхолдери
└─ uploads/               # завантажені зображення
```

---

## Безпека

- Усі сторінки `/manager` і всі маршрути запису `/api/admin/*` — **лише після входу**.
- Публічні `GET /api/*` (читання) — відкриті.
- Пароль адміна хешується `bcrypt`; у відкритому вигляді лишається тільки в `.env`.
- `helmet` (CSP та безпечні заголовки), rate-limit на вхід і на форму звернення, honeypot.

## Деплой на VPS (Ubuntu, приклад)

```bash
# 1. Встановити Node.js 18+ (через nvm або пакетний менеджер)
# 2. Скопіювати проєкт на сервер, у папку /var/www/deputat-site
cd /var/www/deputat-site
npm ci --omit=dev
cp .env.example .env && nano .env      # задати SESSION_SECRET, логін, пароль, SECURE_COOKIES=1

# 3. Тримати процес живим через PM2
npm i -g pm2
pm2 start server.js --name deputat-site
pm2 save && pm2 startup
```

Далі — nginx як reverse-proxy на порт 3000 (HTTPS через Let's Encrypt):

```nginx
server {
    server_name example.com;
    client_max_body_size 12M;          # щоб проходили завантаження фото

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Після налаштування HTTPS поставте в `.env` `SECURE_COOKIES=1` і перезапустіть: `pm2 restart deputat-site`.

### Резервне копіювання
Достатньо зберігати файл **`db/data.sqlite`** і папку **`uploads/`** — це весь контент сайту.
